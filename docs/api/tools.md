## accessibility

### `accessibility.find`

Finds interface elements of a running application by role, title, identifier or value and returns their stable paths for the action tools.

- side effect: read
- default tier: 0
- timeout: 60 s
- idempotent
- output is untrusted data
- macOS permission: accessibility

| Argument | Type | Required | Description |
|---|---|---|---|
| `bundleID` | string | yes | Application bundle identifier, for example com.apple.finder. |
| `identifier` | string |  | Exact accessibility identifier. |
| `includeMenuBar` | boolean |  | Search the menu bar too (default false). |
| `maxDepth` | integer |  | Search depth (default 30). |
| `maxResults` | integer |  | Maximum matches returned (default 20). |
| `role` | string |  | Accessibility role or subrole, for example AXButton, AXTextField, AXMenuItem. |
| `title` | string |  | Case-insensitive substring of the element's title or description. |
| `value` | string |  | Case-insensitive substring of the element's value (never matches secure fields). |

Output fields: `matches`, `searched`, `truncated`

### `accessibility.focus`

Brings a running application to the front and gives keyboard focus to one of its elements, then verifies both. Call before accessibility.typeText.

- side effect: write
- default tier: 2
- timeout: 15 s
- idempotent
- output is untrusted data
- macOS permission: accessibility

| Argument | Type | Required | Description |
|---|---|---|---|
| `activate` | boolean |  | Bring the application to the front first (default true). |
| `bundleID` | string | yes | Application bundle identifier, for example com.apple.finder. |
| `element` | string | yes | Element path returned by accessibility.tree or accessibility.find, for example AXApplication/AXWindow[0]/AXButton[2]. |
| `expectedTitle` | string |  | Optional title or description the element must still have; the action is refused if it changed. |

Output fields: `element`, `focused`, `frontmost`
